# SpaceshipSim

SpaceshipSim is a multiplayer spaceship flight prototype built in C++ with Unreal Engine 5.8. Players pilot a ship with full six-degree-of-freedom style controls (steering, pitch, roll, strafing, and throttle), with a cruise mode for steady travel and a boost for short bursts of speed. A delayed follow camera gives the ship a sense of weight. Flight is handled by a custom `USpaceshipMovementComponent` built on a server/client setup: the server owns the ship's movement, and the client interpolation layer for smoothing remote ships is in progress.

The code is split into three runtime modules. `Spaceship` holds the pawn, movement component, player controller, game mode, and player state. `UserInterface` holds the HUD widget, which also shows debug information. `SpaceshipSim` is the primary game module. You can tune flight values at runtime with console variables under the `spaceship.` prefix (for example `spaceship.CruiseMaxSpeed` and `spaceship.InterpolationDelay`), so you can adjust handling without recompiling. To get started, open `SpaceshipSim.uproject` in Unreal Engine 5.8, let it build the C++ modules, and press Play. Use the editor's multiplayer play options to test client/server behavior.
